# IDX Email Bridge

Use this skill for WhatsApp messages about IDX Exchange real estate email drafts, market report emails, listing alert emails, property summary emails, recommendation digest emails, or approval commands that look like `SEND EMAIL draft_...`.

Do not answer these requests by writing a normal email yourself. The project has a local approval-gated email workflow that must be used.

## Command

Run this local command from any working directory, replacing the message text exactly:

```powershell
node "D:\2026年\intern\IDX_Exchange\openclaw-main\_project\skill\scripts\emailBridge.mjs" --user "whatsapp-demo" --message "<exact WhatsApp message>"
```

Return the command output to the WhatsApp user.

## Required Behavior

- For a draft request such as `Draft a market report email to client@example.com for Irvine`, call the command and return its output.
- For an approval request such as `SEND EMAIL draft_abc123`, call the same command with the approval message and return its output.
- The command stores the pending draft locally, so a later approval message can send the saved draft.
- Do not send email unless the user provides the exact approval line generated by the command.
- If the user includes a signature instruction such as `signature to Best, Merry`, the command will apply it.

## Safety

- Do not print `.env` contents.
- Do not reveal email passwords, app passwords, API keys, or database credentials.
- If the command fails, summarize the error briefly and ask the user to fix the missing configuration.
